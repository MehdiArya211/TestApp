# Raha Assistant 🌱

Personal Assistant application built with .NET MAUI and C#.

## Architecture

- RahaAssistant.Mobile (.NET MAUI Android)
- RahaAssistant.Core (Business Models and Interfaces)
- RahaAssistant.Data (SQLite and Repository)

## Features roadmap

- Dashboard
- Daily / Weekly / Monthly planning
- Tasks
- Goals
- Habits
- Notes
- Notifications
- Dark Mode
- Reports
